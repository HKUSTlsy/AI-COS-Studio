## 分辨率：请求目标，不是假定已实现的硬参数

| 画幅 | 最大精确比例目标（宽 × 高） |
| --- | --- |
| 1:1 | 2880 × 2880 |
| 4:3 | 3264 × 2448 |
| 3:4 | 2448 × 3264 |
| 16:9 | 3840 × 2160 |
| 9:16 | 2160 × 3840 |
| 跟随源图 | 读取主图/干净源图，在边长和总像素限制内寻找比例误差不超过 0.5% 的最大网格尺寸 |

以上以指南记载的 API 包络作为目标参考：单边不超过 3840、总像素不超过 8294400、边长为 16 的倍数、最大长宽比 3:1。超过 3686400 像素的尺寸仍属实验性。未知或超出文档比例范围的源图不强行裁切，改为请求服务可提供的最大原生尺寸并保留原画幅。

Studio 当前两个后端均不能设置 API 的 `size` 或 `quality`：内置 imagegen 只传 Prompt 与参考图，网页仍由用户操作。因此只保存 `control: prompt_only`，不承诺真正硬锁分辨率，也不把分辨率等同于最高质量档。未接入 API Key、付费接口或其他后端。

归档会读取真实文件尺寸并记录 `matched / below_target / different_ratio / different_size / unknown`。未达目标的结果仍正常保存并显示提示，不放大、改名冒充、删除或自动重试。

## 版本保护

新描述仅进入新配置或新批次；旧图、既有 Prompt 快照和等待导回任务不被重写。已经准备好的旧交接需要用户重新准备，才会使用新规则。重拍草稿在确认时会统一补齐尺寸请求；已确认的运行不再改动。
