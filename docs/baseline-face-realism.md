# 基准面部真人化与人工验收

这次重点是基准脸部结构与成像，而不是在后期重拍中增加毛孔词。

## 生效范围

- 新准备的基准 Prompt 加入 `baseline-face-v1`，内置与网页交接共用。动漫提供角色瞳色、妆造与设计，授权脸模提供面部身份和五官结构；原创脸同样遵守可信真人结构。
- 保留已确认瞳色色系与色环，但将插画宝石高光转译为现场光下的真人眼睛和彩色隐形眼镜，不照搬放大眼球或发光材质。不自动卸妆、加斑点、改变年龄或换脸。
- 不更改已保存角色卡、Prompt、脸模或输出。旧交接必须由用户重新准备才会使用新规则；不能按新规则解释旧图片。
- 新基准归档后留在第 3 步。图下方提供原图放大、历史绑定脸模对照、三项人工勾选与备注。放大只是显示缩放，不裁切、锐化或生成新文件。

## 验收与修正

验收检查身份、五官比例与受光肤质。记录在该输出的 `outputAnnotations.faceReview` 中，历次记录保留在 `faceReviewHistory`。采用、收藏和面部验收互不替代；程序不会替用户通过验收。

新基准及其分支在未通过验收时不能创建随机重拍或系列写真；确认重拍批次时再次校验。已通过的上游验收可沿分支继承，界面明确显示其来源。当前图有独立验收时，以当前图为准。

不满意时可返回第 3 步生成新基准，也可通过第 4 步单项调整修正，不要求先接受问题脸。修正图可独立通过验收，原基准的拒绝记录保留。人脸结构/身份本身有问题时，优先重新准备基准，不承诺单项调整可以补救。

旧版本没有新面部协议时显示“旧版本未验收”建议，不追溯阻断已有流程或网页交接；用户主动填写验收后会按其选择执行。运行、排队或等待网页导回期间不允许修改验收，以免改变已冻结输入。

## 面部 A/B 实测

在第 3 步准备一份**新的基准网页交接**，展开“基准面部 A/B 对比（本轮重点）”。

- A：仅移除新增的完整面部块。
- B：保留新增面部块；上一轮 `realism-v1` 肤质基础规则在 A 和 B 中都保留。
- 同一组授权脸模和动漫素材、同一比例与风格、相同参考顺序；在两个独立的 ChatGPT 图片会话各生成一张。
- 不使用旧生成图作基准参考，不在同一会话拿 A 继续修改成 B。
- 对比脸部身份、眼裂/虹膜相对比例、眼睑鼻翼唇缘、面部受光与纹理。构图或姿势更好不算面部规则的证据。
- B 才对应当前交接配置；A 另存比较，不导入 B 的结果槽。首轮两张只供观察，不能证明稳定提升。

重度美颜参考可能限制判断；系统不能还原不可见的未经修饰面部。建议用户自行选择有权使用、五官清楚且修饰较少的参考，但不自动替换现有脸模。

技术测试覆盖 Prompt 分工、受控 A/B、历史身份隔离、验收持久化、并发保护和修正后继续。实际面部效果仍需人工生成与观察，技术通过不等于视觉效果已验证。
