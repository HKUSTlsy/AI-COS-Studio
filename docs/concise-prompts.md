# 简洁摄影 Prompt

新编译采用 `concise-photo-v1`。参考[南鸢关于 MJ V8 摄影提示词的文章](https://x.com/nanyuan0412/status/2094290693086978247)，借鉴画面关系、观看方式和成像分层的写法，不迁移 Midjourney 参数，也不假设不同模型拥有相同表现。

## 写法

- 先说照片里正在发生什么：环境、动作、表情和道具关系放在一起。
- 再说怎么看：景别、机位、构图和前景；焦段只保留为已有选择，不凭空补相机参数。
- 最后补光线与质感，以及必要的身份、范围、参考图用途和输出要求。前后位置不代替明确的冲突优先级。
- 系统只补一段适用于本阶段的真人呈现要求。全身或环境远景不因长篇肤质说明被改成面部特写；局部调整不追加全图美化。
- 不为凑结构而补齐未选择的内容，不删掉光线条件、否定项、授权或单项调整边界。

## 保留哪些内容

完整 Prompt 收藏及已确认适配正文逐字保留。用户导入的摄影包变量、规范片段和参考职责不自动摘要；这次只修订 Studio 自带的 24 条模块规范片段。原文、旧版本、历史作品、待交接素材和重试输入不重编译。已编辑的内置模块若不再匹配原预设，跳过而不覆盖。

新基准仍保留真人五官转换、脸模身份及人工面部验收；重拍仍受角色演绎与服装授权控制；多人逐人映射不因追求短文案而省略。阿茶署名仍由原来的网页重拍规则添加。目标画幅和最大原生像素请求不变，实际尺寸以文件为准，不强制裁切、放大或自动重试。
